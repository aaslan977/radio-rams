# Radio

**Демо: [radio-rams.vercel.app](https://radio-rams.vercel.app/)** — открывается
без установки, на телефоне ставится на домашний экран.

Веб-радиоприёмник (PWA) в эстетике Дитера Рамса / Braun: один плоский корпус,
круглая кнопка вкл/выкл, крупная решётка динамика, диск тюнинга, реальные
интернет-радиостанции. Контекст и требования — в [BRIEF.md](./BRIEF.md).

## Стек

Vite + React + TypeScript, Tailwind CSS v4, Zustand, Web Audio API, Framer Motion,
@use-gesture/react, vite-plugin-pwa, Vitest.

## Команды

```bash
npm install       # установка зависимостей
npm run dev       # dev-сервер (http://localhost:5173)
npm run build     # прод-сборка + генерация PWA (manifest/service worker)
npm run preview   # локальный просмотр прод-сборки
npm run test      # тесты (Vitest)
npm run lint      # линт (oxlint)

npm run generate:icons  # перегенерировать растровые иконки PWA из public/icons/icon.svg
```

Иконки лежат в репозитории готовыми — команда нужна только после правки
исходного `icon.svg`.

## Структура

```
src/
├── components/   # DeviceShell, PlayButton, Display, Equalizer, TextScramble,
│                 # SpeakerGrille, StationTicks, JogWheel
├── hooks/        # useAudioPlayer (live-стрим + retry), useAudioAnalyser,
│                 # useMediaSession (экран блокировки, кнопки на наушниках)
├── store/        # Zustand: текущая станция, статус
├── lib/          # данные и чистая логика без React:
│                 # stations.ts — список станций
│                 # spectrum.ts — логарифмическая группировка бинов FFT
│                 # grille.ts   — шаг сетки и тёмное пятно решётки
│                 # wheel.ts    — кратчайший поворот диска между станциями
│                 # sound.ts    — общие настройки звука интерфейса
│                 # haptics.ts  — обёртка над Vibration API
├── types/        # общие типы (Station, PlaybackStatus)
├── styles/       # Tailwind + design tokens в @theme
└── test/         # setup для Vitest
```

Тесты лежат рядом с кодом (`*.test.ts`), а не отдельным деревом.

Компоненты не читают стор и не трогают аудиограф потока — данные приходят
пропсами из `App.tsx`, работа с `<audio>` и `AnalyserNode` живёт в хуках.
Подробнее о слоении и о том, что из этого правила вынесено сознательно, —
в [CLAUDE.md](./CLAUDE.md).

## Статус

Рабочее приложение, а не прототип: восемь проверенных станций, приём и
переключение работают на десктопе и на телефоне. Живёт на
[radio-rams.vercel.app](https://radio-rams.vercel.app/).

**Приём.** Play/pause одной кнопкой, дискретное переключение станций диском —
перетаскиванием и стрелками с клавиатуры. При обрыве потока идут автоматические
ретраи текущей станции, после их исчерпания на дисплее «No signal». Последняя
станция восстанавливается при следующем открытии.

**Визуализация.** Live-эквалайзер на `AnalyserNode`: логарифмическая группировка
бинов FFT, асимметричное сглаживание, буфер канваса под `devicePixelRatio`. Там,
где движок отдаёт нули при нормально играющем звуке (WebKit, антифингерпринтинг
в Yandex Browser), эквалайзер переходит на декоративную анимацию — оговорки к
этому компромиссу в разделе 4 [BRIEF.md](./BRIEF.md).

**Отклик.** Звук интерфейса синтезируется на лету через
[@rexa-developer/tiks](https://www.npmjs.com/package/@rexa-developer/tiks), без
аудиофайлов. Вибрация — только на Android: WebKit Vibration API не
реализовывал, на iPhone её нет и не будет.

**Система.** Media Session отдаёт название и жанр станции на экран блокировки и
в шторку уведомлений; play/pause и переключение станций работают с кнопок
наушников.

**Доступность.** Полное управление с клавиатуры, зоны нажатия не меньше 28×28,
видимый фокус, текущая станция объявляется скринридеру.

**PWA.** Устанавливается, оболочка работает офлайн, раз в час проверяется
обновление — открытая часами вкладка не остаётся на старом бандле.

Открытые вопросы закрыты — см. раздел 7 в [BRIEF.md](./BRIEF.md).

## Атрибуция

Композиция интерфейса взята с [drams.framer.website](https://drams.framer.website)
(компонент "Digital Rotary Radio Player") — по условиям сайта эти Framer-компоненты
свободны для личного и коммерческого использования при указании авторства.

Стиль ручки тюнинга (компонент "Dail 1") и кнопки play (компонент "Button 4")
взяты из файла Figma Community ["Components inspired by Dieter Rams' design principles"](https://www.figma.com/design/Dgye0vkg7rg231FvWD9XLm/Components-inspired-by-Dieter-Rams--design-principles--Community-) —
свободное использование.

Список радиостанций и лицензии на использование их потоков — в [BRIEF.md](./BRIEF.md#4-технические-ограничения).
